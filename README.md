
# KEYAM SPORTS (Mac + AI Edition)

## Quick Start (Mac)
1) Install Node LTS from https://nodejs.org
2) In Terminal:
   cd /path/to/keyam-sports-mac-ai
   npm install
   npm run dev
3) Open http://localhost:3000

## Deploy
- Push this folder to GitHub
- Import to Vercel → Deploy

## AI
- Add OPENAI_API_KEY in Vercel → Settings → Environment Variables
- Then the 'Generate AI Headline' button will produce real headlines
